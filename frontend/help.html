Workflow · where to start
  1. Ingest
    Capture or import frames — live game, YouTube, or a local video file.
  2. HUD mask
    Mask the static game UI once per game version so it never confuses the model.
  3. Label
    Auto-label with YOLO + SegFormer, then fix the uncertain frames by hand.
  4. Train
    Train the perception model on confirmed labels.
  5. Compare
    Your model vs YOLO, side by side, with summary metrics.
  6. Telemetry
    Verify Forza is broadcasting on UDP.
  7. Drive
    Engage the rule-based or PPO policy through the virtual gamepad.
