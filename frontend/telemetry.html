Verify the game is broadcasting clean signal.

Forza Horizon streams data sets over UDP. This page confirms packets are arriving, parses speed / gear / position / lap, and plots the track map live so you can sanity-check the feed before driving.

What this page will surface
UDP listener
Packet rate, source address, dropped / malformed counters. Big red banner if nothing arrives within a few seconds.
Live readout
Speed (mph + kph), gear, RPM, throttle, brake, steer angle. Tabular numerals so the values stop jittering as they change.
Track map
Top-down trace of the car position over the last few laps, normalized so the same track lines up across runs.
Lap deltas
Sector + lap times against the best of the session, with a per-corner heatmap of throttle/brake choices.
